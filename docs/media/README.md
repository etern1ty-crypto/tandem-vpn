# Media assets

The README references these files. Capture them and drop them here (filenames must match).

Recommended tool: [ScreenToGif](https://www.screentogif.com/). The app UI is dark, so record on a
neutral desktop and keep the window at its default size (980×720).

## Required

### `hero.gif` — the money shot (~8–12s, keep under ~5 MB)
Record the full happy path in one take:
1. Launch tandem-vpn (Administrator).
2. Click **«Скачать и установить Zapret»** → let it finish.
3. Pick a strategy from the dropdown.
4. Click **«Установить в автозапуск»** → status badges flip to green `RUNNING`.
5. Click **«Запустить тесты»** → targets show ✓.

Trim dead air (the download wait) so it stays snappy. This single GIF is what converts a
visitor into a star — spend the time to make it clean.

The main window with a strategy installed and green statuses.
