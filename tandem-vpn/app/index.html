Движок работает как служба Windows и через TUN-интерфейс маршрутизирует трафик: заблокированные РКН-домены — через WARP, домены, блокирующие РФ — через Goida, остальное — напрямую.

Управление

«Запустить движок» устанавливает и стартует службу с текущей конфигурацией (WARP и выбранный Goida-сервер подхватываются автоматически). Требуются права администратора.

WARP даёт бесплатный туннель Cloudflare для сервисов, которые РФ замедляет, но не блокирует. После создания аккаунта нажмите «Запустить движок» на вкладке «Движок», чтобы применить.

Списки блокировок

Список доменов, блокирующих доступ из РФ (для маршрута через Goida), берётся из сообщества Re-filter-lists. РКН-блокировки для WARP подгружаются движком автоматически.
