Умный локальный VPN-тандем для Windows — **без собственного сервера**.

tandem-vpn — это удобный графический интерфейс поверх движка [**sing-box**](https://github.com/SagerNet/sing-box).
Он поднимает системный TUN-туннель и **маршрутизирует трафик по трём направлениям**:

- **direct** — обычные сайты идут напрямую, без задержек;
- **WARP** — заблокированные РКН ресурсы идут через бесплатный туннель Cloudflare;
- **Goida** — сервисы, которые сами блокируют доступ из РФ, идут через публичные конфиги сообщества (VLESS / Trojan / Shadowsocks).

Не нужно вручную качать ядра, писать конфиги и разбираться с командной строкой — всё делается кнопками.

## ⚡ Быстрый старт

1. **Скачайте** установщик (`.msi` или `.exe`) со страницы [Releases](https://github.com/etern1ty-crypto/tandem-vpn/releases), установите и запустите приложение **от имени администратора**.
2. На вкладке **«Движок»** нажмите **«Скачать sing-box»** — приложение само подтянет актуальный релиз ядра.
3. *(для заблокированных РКН сайтов)* На вкладке **«WARP»** нажмите **«Скачать wgcf»**, затем **«Создать WARP-аккаунт»**.
4. *(для сайтов, блокирующих РФ)* На вкладке **«Goida»** нажмите **«Загрузить список»**, затем **«Тестировать»** и выберите быстрый сервер.
5. Вернитесь на вкладку **«Движок»** и нажмите **«Запустить движок»**.

**Готово.** Заблокированное открывается через WARP, «антироссийское» — через выбранный Goida-сервер, остальное — напрямую.

## 🧠 Как это работает

```
                       ┌─────────────────────────────┐
   весь трафик  ──────▶│      sing-box (TUN)         │
                       │      правила маршрутизации  │
                       └──────────────┬──────────────┘
              ┌───────────────────────┼───────────────────────┐
              ▼                       ▼                       ▼
          direct                    WARP                    Goida
      (обычные сайты)      (РКН-блокировки, через      (сайты, блокирующие РФ,
                            Cloudflare WARP/wgcf)        публичные VLESS/Trojan/SS)
```

- **Списки маршрутизации.** РКН-блокировки идут через WARP автоматически; список «блокирует РФ» для Goida тянется из сообщества (Re-filter-lists) по кнопке.
- **Персональные правила.** На вкладке «Правила» можно принудительно отправить любой домен в `direct`, `warp` или `goida`.
- **Тест Goida.** При нажатии «Тестировать» движок поднимается в тест-режиме, каждый сервер пингуется через Clash API, «мусор» с задержкой ≥ 200 мс отсекается, а рабочие серверы группируются по странам — выбираете лучший в один клик.

> **Нет главного сервера.** Приложение ничего не хостит: WARP идёт в сеть Cloudflare, Goida-конфиги тянутся прямым запросом к GitHub, ядро sing-box работает локально. Никакого нашего бэкенда и телеметрии.

## 🛠️ Возможности

- **Управление движком**: скачивание sing-box, установка/запуск/остановка службы Windows одной кнопкой.
- **Cloudflare WARP**: скачивание `wgcf`, создание бесплатного аккаунта и генерация WireGuard-профиля.
- **Goida-подписки**: загрузка публичного списка конфигов, массовый пинг-тест с фильтрацией и выбором по странам.
- **Гибкая маршрутизация**: авто-списки блокировок + персональные правила по доменам.
- **Тесты доступности**: проверка целевых сайтов (YouTube, Discord, GitHub и др.) прямо из интерфейса.

## ❓ FAQ

**Q: Почему нужны права администратора?**
A: sing-box создаёт системный TUN-интерфейс и устанавливается как служба Windows — для этого требуются системные привилегии.

**Q: Антивирус ругается на файл.**
A: Приложение управляет сетевым туннелем и службой, поэтому некоторые антивирусы реагируют ложно (False Positive). Добавьте папку с программой в исключения.

**Q: В играх с античитами появились проблемы.**
A: Остановите движок (кнопка «Остановить») на время игры — весь трафик снова пойдёт напрямую.

## 💻 Для разработчиков

Требования: Rust (stable), Node 20+, а для Windows-сборки — WebView2.

```bash
# Фронтенд
cd app && npm install && npm run build

# Проверки ядра (кроссплатформенно, без сети)
cargo fmt --all -- --check
cargo clippy --workspace -- -D warnings
cargo test -p tandem-core

# Запуск десктоп-приложения (нужен tauri-cli: cargo install tauri-cli)
cd app && cargo tauri dev
```

Архитектура: кроссплатформенное ядро `core/` (`tandem-core`) генерирует конфиги sing-box и планирует
команды за абстракцией `Sys`, поэтому логика тестируется на любой ОС; тонкий слой команд Tauri в
`app/src-tauri/` адаптирует ядро к GUI, а весь UI — на ванильном JS в `app/src/`.

### Релизы

Релиз собирается автоматически при пуше git-тега вида `vX.Y.Z`:

```bash
git tag v0.2.0
git push origin v0.2.0
```

CI (`.github/workflows/release.yml`) прогоняет fmt + clippy + тесты, собирает Windows-инсталляторы
(`.msi` и `.exe`) через `tauri-action` и публикует их в GitHub Release. Сборку можно также запустить
вручную из вкладки **Actions** (workflow «Build and Release»), указав нужный тег.
