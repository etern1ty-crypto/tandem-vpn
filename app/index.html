01

Проверяемый пакет

Каталог данных: защищённый Program Files\TandemWorkbench. Для замены пакета сначала удалите службу Tandem.

Собственная контрольная сумма неизвестного ZIP не доказывает его подлинность. Сверяйте её с независимым доверенным источником.

02

Стратегия и служба

Никаких .bat-процессов

Автозапуск включается только при установке службы. Закрытие окна не останавливает службу. Поддержка конкретной стратегии проверяется до запуска.

03

Настройки и проверка

Перед изменением настроек остановите службу. После изменения игровых портов переустановите её. HTTP 403 означает ответ сервера, а не разрыв соединения.

Дополнительные операции: IPSet и hosts

Редактирование hosts не включено по умолчанию. Разрешены только публичные IP и домены из явного списка в конфигурации.
